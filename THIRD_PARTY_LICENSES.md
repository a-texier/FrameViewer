# Third-party licenses

The root `LICENSE` applies to original FrameViewer code only. A dependency,
file, directory, or dataset carrying its own license or attribution remains
governed by those terms. Neither the root license nor a commercial agreement
for FrameViewer replaces them.

FrameViewer uses Python packages including PySide6, OpenCV, NumPy, pandas,
Polars, PyInstaller, Shiboken and their transitive dependencies. This list is
an overview, not a complete software bill of materials.

The tutorial dataset has its own attribution and license information in
`data_test/ATTRIBUTION.md`.

Before a public or commercial release:

1. Preserve every third-party license, legal file, and attribution file.
2. Generate an SBOM and review all direct and transitive dependencies.
3. Review dataset terms separately from source-code licenses.
4. Do not represent third-party code or data as project-owned material.
5. Obtain separate rights when a dependency is incompatible with the intended
   deployment or distribution model.
