# Contributing

The project uses a dual-license model. Do not accept an external contribution
until the repository owner has configured and reviewed a Contributor License
Agreement (CLA) suitable for dual licensing.

The CLA must allow the project copyright holder to distribute the contribution
under both `AGPL-3.0-only` and separate commercial terms while preserving the
contributor's authorship. A Developer Certificate of Origin alone does not
necessarily provide the relicensing rights required by this model.

Until that process is available, external pull requests should be limited to
discussion or rejected without merging. Employees and contractors must also
have written intellectual-property terms that assign or license the necessary
rights to the project owner.

Contributions must not add credentials, private datasets, private adapters,
model weights, or third-party code without a documented and compatible
license.
